# Javaで作成したネットワーク対戦ゲーム

和歌山大学のネットワークシステム開発演習（通称: Java演習）で開発したものです。

- 授業での提出時点から改良・機能拡張を行っています。
- **現在は壊れています。**
  - モニターの解像度が変わるとレイアウトが崩れる・エイムがずれる
  - プレイを始めるとクラッシュする（原因調査中）
